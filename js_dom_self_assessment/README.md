# JavaScript and DOM self assessment

Fifty San Francisco Airbnb listings loaded from a local JSON file with fetch and rendered into the DOM, with search, sorting, a clickable price histogram, and a compare bar.

Live page: https://sukjinmun.github.io/CS5610_submission_SJM/js_dom_self_assessment/

Data: Inside Airbnb, San Francisco, September 2023, first five hundred rows.

Local: `npm install`, then `npm start` and open http://localhost:8080.
