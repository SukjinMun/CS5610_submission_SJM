The home page loads a local JSON file with fetch and await, takes the first fifty listings, and builds one card per listing in the DOM. Each card shows the photo, name, price, host name and photo, rating, description, and amenities.

The controls filter by name, sort by price or rating, and report how many of the fifty are on screen. The price histogram splits the fifty prices into ten buckets, and clicking a bar narrows the list to that range. Up to three cards can be checked for comparison, and those appear side by side in a bar at the bottom of the window.

The data is the San Francisco listings file from Inside Airbnb, September 2023, trimmed to the first five hundred rows.
